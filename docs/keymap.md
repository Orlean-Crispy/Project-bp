# 键位方案（默认建议，待试玩确认）

> 状态：**建议稿**。计划书 §2.2 已否决「Q 一键承载 wallrun / wallclimb / vault」，
> 但没有给出替代方案；M3 的验收「按键分离验证通过」需要它，所以先定一版默认值。
> 改这里就要同步改 `sim/move/pmove.h` 的 `MoveInput` 映射（目前只在 headless 测试里用）。

## 移动

| 动作 | 键 | 说明 |
|---|---|---|
| 跳跃 | `SPACE` | 二段跳（impulse jump）留到接入资源系统后 |
| 蹲 | `CTRL`（按住） | 起蹲状态，受头部空间限制 |
| 滑铲 | `SHIFT` | 落地/地面且速度 ≥ 5.08 m/s 时触发，消耗 1 次 |
| 墙跑 | `Q` | **仅空中**，需要墙面 `_wallrunnable 1`，按住维持 |
| 爬墙 | `E` | 地面/空中都可用，需要墙面 `_climbable 1`，按住维持 |
| 翻越 | `V` | 面前 0.46–1.22 m 的台沿，消耗 1 次 |
| 冲刺 | `F`（或双击 WASD） | 独立冷却 1 s，不消耗 parkour 次数 |

## 为什么这么分

| 原则 | 体现 |
|---|---|
| 高频繁用键不放 Q | 蹲/滑铲/跳都在左手区，不参与「上下文猜意图」 |
| 三个垂直能力各自一键 | 墙跑 Q、爬墙 E、翻越 V——不会再出现「想爬墙结果翻了箱子」 |
| 冲刺不占 parkour 资源 | 计划书里 dash 是「开发分支能力」，用冷却而不是次数，避免和五件套抢资源 |
