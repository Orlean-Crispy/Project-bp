## 2. 建议顺序（每步都要带 headless 判据）

1. **射击最小闭环**：WeaponDef(toml) → 开火输入 → hitscan（复用 hitbox 历史）→ 三段伤害 →
   hp/armor 进快照 → 死亡/重生。判据：固定靶命中/未命中、三段倍率、TTK 0.6–1.2 s。
2. **A1/A2/A5 接入**：信令线程 + MATCH_START 触发 UDP 加入；票据接 HELLO；槽位复用。
   判据：两进程 30 s 断线→重连回原槽、dev < 0.01 m。
3. **地图/UI/音频**：40×40 图、局内菜单、脚步/枪声。

## 4. 本轮已确认的功能性问题（不是债）

- **槽位只增不减**：`NetServer::add_client` 的槽位由调用方给；bridge 的 `m_next_slot` 和
  net_loop 的 `next_slot` 都只 `++`。超时释放 slot 1 后，新客户端仍拿 slot 2 → 超出人数。
  修法：`add_client(..., -1)` 选第一个 inactive 槽位；属于 A5 接入的一部分。
- **快照没有 hp/armor**：即使现在有 hitscan，也打不掉人；射击与伤害联网必须同批做。
