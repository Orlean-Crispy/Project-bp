# 1. 一句话

> **IMPULSE：动起来才有力。**

一个词同时说清三件事——**物理上的冲量、玩法上的动量、系统里的移动资源**。

---

## 1.1 名称体系（三层）

**对外名与内部代号是两套东西，各管各的，不冲突。**

| 层级 | 名称 | 作用域 | 用途 |
|---|---|---|---|
| **对外正式名** | **IMPULSE** | 玩家可见 | 商店页、标题画面、宣传物料、社区账号 |
| **社区简称** | **IMP** | 玩家可见 | HUD、昵称、聊天、版本号 |
| **内部代号** | **Project Breakpoint**（**Project Bp** / **bp**） | 仅团队 / 仓库 | 仓库名、构建产物、分支名、内部文档、issue |

### 为什么内部还留着 Breakpoint

| 理由 | 说明 |
|---|---|
| **有含义** | breakpoint = 断点（调试器的断点） + 突破点（爆破的破点），双关成立 |
| **已在用** | 计划书 v0.1–v0.3、目录结构、之前的讨论全部用这个名字，改造成本不值得 |
| **可检索** | `bp` 两个字母，比 `impulse` 更适合做文件名前缀与分支名 |
| **不对外** | 与育碧《幽灵行动：断点》（Breakpoint）的撞名风险只在公开场合成立，内部无影响 |

### 使用规范

| 场景 | 用哪个 |
|---|---|
| 仓库名 | `project-bp` 或 `bp` |
| 分支 / issue 前缀 | `bp/` |
| 构建产物 | `bp.exe` / `libbp.a` |
| C++ 命名空间 | **`bp::`** |
| 计划书 / 设计文档 | Project Breakpoint |
| 游戏内资源术语 | **impulse**（小写，指 0–6 次资源） |
| 玩家看到的一切 | **IMPULSE** / **IMP** |

> **一句话**：**对外叫 IMPULSE，对内叫 Project Bp，系统里那个资源叫 impulse。**
> 三者不互斥，因为它们服务于不同的读者。

# 2. 为什么是 IMPULSE

## 2.1 物理层：它本来就是一个精确的物理量

```
J = F · Δt = Δp
```

| 符号 | 含义 |
|---|---|
| **J** | 冲量（impulse） |
| **F** | 力 |
| **Δt** | 作用时间 |
| **Δp** | 动量的变化量 |

冲量的定义是「**力在一段时间上的累积**」。

这个定义本身就是游戏的核心机制：

> **你不是靠一次点击造成伤害，而是靠持续施加的力（移动、压制、追击）累积出结果。**

## 2.2 玩法层：它描述的是「移动即力量」

本项目的三个设计支点，全部落在「冲量」这个词上：

| 设计支点 | 与冲量的关系 |
|---|---|
| **Apex 式 parkour** | 滑铲、墙跑、爬墙、翻越——每一次都是给身体施加冲量 |
| **长 TTK（0.6–1.2s）** | 伤害是累积的，不是瞬间的——和冲量「力的时间累积」同构 |
| **受伤减速 + 爆头终结** | 改变对方的动量状态（减速 = 削减动量，爆头 = 一次性巨大冲量） |

**它不是「速度」，而是「力的累积」。** 这个词选得比 `VELOCITY`、`SPEED`、`REDLINE` 都准，因为那些只说了快，没说**为什么快有意义**。

## 2.3 系统层：游戏里已经有一个东西叫 impulse

这不是硬凑——**它已经在技术方案里了**。

Red Eclipse 2 的 parkour 资源系统，单位就叫 **impulse**：

```
默认上限：6 次连续移动
恢复条件：触地开始充能
```

所以：

| 层面 | impulse 指什么 |
|---|---|
| 游戏标题 | 整个玩法哲学 |
| 系统内部 | 移动资源计数（0–6） |
| 玩家口中 | 「没 impulse 了」「省一次 impulse」 |

**名字、机制、术语是同一个词。** 这是命名能达到的最好状态——不是贴上去的标签，是从系统里长出来的。

# 3. 三层同义：名字、玩法、系统是同一个词

```
        ┌─────────────────────────────┐
        │         IMPULSE             │
        │   （游戏名 · 玩法哲学）      │
        └──────────────┬──────────────┘
                       │
        ┌──────────────┴──────────────┐
        │                             │
   ┌────▼─────┐                 ┌─────▼────┐
   │ 物理定义  │                 │ 系统资源  │
   │ J = F·Δt │                 │ 0 – 6 次 │
   │  = Δp    │                 │ 落地充能  │
   └──────────┘                 └──────────┘
```

这三层不是比喻关系，是**同一个概念在不同尺度的投影**：

| 尺度 | 表现 |
|---|---|
| 微观（一次动作） | 滑铲给身体一个冲量 |
| 中观（一局对枪） | 持续压制累积出击杀 |
| 宏观（整局游戏） | 你的移动资源（impulse）决定你能绕几次后 |

> **一个好的名字，应该能在三个尺度上都成立。** 这是检验名字的方法。

# 4. 缩写 IMP 的双关

`IMPULSE` 的缩写是 **IMP**。

而在英语里，**imp** 是「小恶魔」：

| 出处 | 含义 |
|---|---|
| 古英语 *impa* | 幼芽、接穗 |
| 弥尔顿《失乐园》 | 小魔鬼、堕落天使的幼体 |
| 奇幻/游戏传统 | 淘气、狡黠、体型小但难缠的小怪 |

### 为什么这是「真双关」而不是硬凑

| 层面 | IMP 的含义 |
|---|---|
| 技术面 | IMPULSE 的自然缩写 |
| 性格面 | 小恶魔——快、刁、不正面硬刚 |
| 与 Doom 的呼应 | 同为「恶魔」意象，但 Doom 是沉重的毁灭，IMP 是轻快的骚扰 |
| 与玩法的对应 | 你打不过正面，就绕后、就爬墙、就从上面下来 |

**这恰好补上了 IMPULSE 唯一的短板。**

`IMPULSE` 单独看偏「工程感」，像一个物理课本里的词；`IMP` 把它拉回到「有攻击性的小家伙」这个形象上。

### 使用建议

| 场景 | 用哪个 |
|---|---|
| 正式名、商店页、标题画面 | **IMPULSE** |
| 社区昵称、玩家自称 | **IMP** / **IMPs** |
| HUD 资源条标签 | **IMP**（短，省空间） |
| 版本号 | `IMPULSE 0.1` 或 `IMP 0.1` |
| 代码命名空间 | `imp::` |

# 5. 符号系统

## 5.1 主符号：J

冲量的标准符号是 **J**。

| 符号 | 是否标准 | 说明 |
|---|---|---|
| **J** | ✅ **标准** | 来自 *impulse*，用 J 是为了避开 I |
| p | ✅ 标准 | 动量（momentum） |
| ~~I~~ | ❌ 不标准 | I 在物理学里通常指**转动惯量**（moment of inertia），用它会混淆 |

> **所以不是「只有 I 或 J」，物理上只有 J。**

## 5.2 辅助符号：Δp

冲量-动量定理：**J = Δp**

`Δp`（读作 delta-p）比单字母 J 更适合做视觉符号：

| 优势 | 说明 |
|---|---|
| **Δ 本身是图形** | 一个实心三角，天然有方向感和速度感 |
| **Δ 的含义正好** | 「变化」——对应核心主张「动起来才有输出」 |
| **可读性** | 玩家会念「delta p」，有辨识度，不难读 |
| **可组合** | `Δp` 可以拆开做动效：Δ 先出现，p 再跟上 |

## 5.3 三个 logo 方向

### 方向 ①：J 变形为抛物线（**推荐**）

```
      ╭─────▶
     ╱
    ╱
   J
```

**做法**：把 J 的钩子末端拉长、加箭头，形成一条**抛物线轨迹**——正是「冲量作用于物体后的运动路径」。

**优点**：
- 单字母，HUD、图标、favicon 都放得下
- 有动势，不呆板
- 一眼可辨，缩小到 16px 仍可读

### 方向 ②：Δp 组合

```
   ▲
  ╱ ╲   p
 ╱___╲
```

**做法**：Δ 做成向左倾斜的实心三角，p 用紧凑的小写紧贴其右下。

**优点**：
- 更有「公式感」，适合硬核/技术调性
- 两个字符的组合有层次

**缺点**：缩小后 p 容易糊，需要单独做一个简化版图标。

### 方向 ③：矢量折线

```
 ●───────╮
          ╲
           ▶
```

**做法**：一条折线，起点一个圆点，中途明显偏转，末端箭头。

**含义**：这**就是**冲量的视觉定义——「方向被改变」。

**优点**：最抽象、最独特，不像任何现成游戏的 logo。
**缺点**：需要配文字才认得出是 IMPULSE。

## 5.4 符号使用规范

| 场景 | 符号 |
|---|---|
| 应用图标 / favicon | **J**（方向 ①） |
| 标题 logo | **J** + 全名 IMPULSE |
| HUD 的 impulse 资源条 | 小号 **J** 图标 ×6 |
| 击杀提示 / 连杀 | **Δp** |
| 加载画面 / 转场 | 矢量折线（方向 ③） |
| 社区头像 | **J** 或 **IMP** 字样 |

# 6. 语言一致性：让名字从系统里长出来

这是整个命名方案里最值得做的一件事：**游戏内所有术语都围绕 impulse 展开**。

| 系统元素 | 命名 | 效果 |
|---|---|---|
| parkour 资源 | **impulse**（0–6） | 名字 = 资源 |
| 资源耗尽 | *"out of impulse"* / *"impulse depleted"* | HUD 提示语 |
| 落地充能 | *"impulse recharging"* | 状态提示 |
| 加速区 / 弹跳板 | **impulse zone** | 地图元素 |
| 命中反馈 | **IMPACT** | 和 IMP 同源 |
| 玩家自称 | **IMPs** | 社区语言 |
| 一击必杀 | *"full impulse"* | 满资源时的爆头 |

**这样做的收益**：

1. 玩家不需要记两套词（游戏名 + 系统名）
2. 每次看到 HUD 上的 "IMP" 都在强化品牌
3. 社区自然产生简称（IMPs），不需要官方推

> **反面例子**：名字叫 `NOVA`，但游戏里没有任何东西叫 nova——那名字就只是包装纸。

# 9. 与其他 FPS 命名的对照

## 9.1 三条主流路径

| 路径 | 代表 | 特征 |
|---|---|---|
| **描述型** | Counter-Strike、Battlefield、Overwatch、Squad | 直接说玩法，安全但平庸 |
| **借词型** | Doom、Quake、Halo、Unreal、Tarkov | 借一个已有情绪的词 |
| **造词型** | Valorant、Apex、Titanfall | 新造词，需要宣传支撑 |

**IMPULSE 属于「借词型」**——借的是一个**已有精确含义的物理词**。

## 9.2 三个值得学的案例

### DOOM：借一句电影台词

开发代号是 ❌ **"Green and Pissed"**（绿盔甲 + 火球）。

卡马克看了《金钱本色》，汤姆·克鲁斯拎着球杆盒说 **"Doom"**，就定了。

> **启示**：不必自创词，借一个已经很有力的词更有效。

### QUAKE：从开发过程里长出来

名字来自罗梅罗跑团时写的一张武器卡（Quake），后来给了一个角色，角色被忘了，名字留给了游戏。

> **启示**：名字可以从开发过程里自然产生，不必一开始就锁死。

### HALF-LIFE：原名 Quiver，改名因为「不陈腐」

原叫 **Quiver**（箭袋，取自史蒂芬·金《迷雾惊魂》的 Arrowhead 基地）。

Gabe Newell 说改成 Half-Life 有两个原因：
1. 契合主题，且**不陈腐**
2. **有一个对应的视觉符号**：希腊字母 **λ**（Lambda），正是半衰期公式里的衰变常数

> **这是最值得学的一条**：名字要能给出一个**符号**。
>
> ⚠️ 顺便纠正一个常见误解：**「半条命」是中文玩家的二次创作，不是官方双关。** 官方中文名到《半衰期：爱莉克斯》才定为「半衰期」。

## 9.3 五条规律

| # | 规律 | IMPULSE 是否满足 |
|---|---|---|
| 1 | 一个词，不加前缀 | ✅ |
| 2 | 1–2 个音节 | 🔸 两音节（im-pulse） |
| 3 | **能做成一个符号** | ✅ J / Δp |
| 4 | 带情绪，不带说明书 | ✅ IMP 补上了攻击性 |
| 5 | 不解释也能懂 | 🔸 需要一点物理常识，但不懂也不影响 |

# 10. 被否决的候选（留档）

## 10.1 英文

| 候选 | 否决理由 |
|---|---|
| ~~**Project Breakpoint**（作为对外名）~~ | **降级为内部代号**（见 §1.1）。作为对外名会与育碧 2019《幽灵行动：断点》混淆 |
| ~~VAULT~~ | 只覆盖「翻越」一个动作，太窄 |
| ~~BREACH~~ | 战术感够，但与彩虹六号强绑定 |
| ~~TRACE~~ | 技术味过重，玩家不一定懂「扫掠」 |
| ~~SLIDE~~ | 太普通，像功能名不像游戏名 |
| ~~REDLINE~~ | 速度感有，但赛车游戏大量使用 |
| ~~KINETIC~~ | 干净，但太抽象，没有攻击性 |
| ~~SLIPSTREAM~~ | 画面感好，但三个音节偏长 |
| ~~BREAKNECK~~ | 像形容词，不像名字 |
| ~~TERMINAL~~ | 容易联想到 1995 年《Terminal Velocity》 |
| ~~PINCER~~ | 「钳形攻势」最独特，但中文「钳形」略生僻 |
| ~~HOTZONE~~ | 已被多个作品使用 |
| ~~OVERRUN~~ | 动感强，但偏「大战场」气质 |
| ~~**IMPULSE 不够狠**~~ | **该判断被 IMP 的「小恶魔」双关推翻** |

## 10.2 中文

| 候选 | 否决理由 |
|---|---|
| ~~《破点》~~ | 双关好（爆破点 + 突破点），但作为正式名偏「手游感」 |
| ~~《锋线》~~ | 好听，但偏 MOBA |
| ~~《动量》~~ | 干净，但不够狠 |
| ~~《跃界》~~ | 有科幻感，略文艺 |
| ~~《突入》~~ | 直接，但像手游 |
| **《冲量》** | 保留为中文正式译名（备选），或直接不译 |

> **最终建议**：中文不强行翻译，直接用 **IMPULSE**（CS、瓦、Apex 在国内都不译）。需要中文时用**《冲量》**。

> 玩法重心从「纯移动」变成了「移动 + 破坏」双支柱。
>
> **本节与 §1–§11 的结论并列，不替代前文。** 前文照旧成立；
> 本节只回答一个新问题：**重心偏移之后，IMPULSE 这个名字还站得住吗？**

---

## 附-1 结论

> **站得住，而且比原来更贴。**

深化 B 把 IMPULSE 从一个「移动游戏的名字」升级成一个「**关于力的游戏的名字**」。

原来它说的是「**我怎么动**」；现在它说的是「**我怎么改变这个世界**」。

---

## 附-2 证据一：破坏本身就是冲量

§8.3.4 的「材质 × 手段」矩阵，本质是一句话：

> **不同手段 = 不同大小的冲量；不同材质 = 不同大小的屈服强度。**

| 手段 | 物理本质 | 能开出什么 |
|---|---|---|
| **C4** | **集中冲量**（爆轰） | 3×3 站立通行 |
| **破门锤** | 脉冲冲量（1.2 s 一次） | 2×2 蹲行 |
| **霰弹** | 小冲量累积 | 2×1 射击孔 |
| **步枪** | 微小冲量 | 1×1 观察孔（仅玻璃 / 木板） |

**「普通子弹对混凝土无效」这条决定，用冲量解释是最自然的**：

不是因为「混凝土血厚」，而是因为**单位面积的冲量不够**。

一旦这样理解，「材质表」就不再是一张数值表，而是一张**冲量 - 屈服对照表**。

---

## 附-3 证据二：四档破坏 = 冲量的四个量级

§8.3.3 那张 chunk 表，其实可以画成这样一张图：

```
冲量 ↑
  │                           ┌── 站立通行 3×3（C4）
  │                   ┌───────┤
  │           ┌───────┤       └── 蹲行 2×2（破门锤 ×4）
  │     ┌─────┤       └─────────── 射击孔 2×1（霰弹）
  │ ────┤     └─────────────────── 观察孔 1×1（步枪）
  └─────┴─────────────────────────────────▶ 材质强度
```

**同一堵墙，施加不同的冲量，得到不同的破坏程度。**

这不是比喻，是物理事实。

而且它解释了为什么「观察孔 / 射击孔」这两档特别有价值：

> **它们是「冲量够改变信息、但不够改变通路」的中间态。**

这个中间态在 CS 里做不到——CS 的门只有「开 / 关」两态，
而这里有三态：**能看不能过 / 能打不能过 / 能过**。

---

## 附-4 证据三：三个尺度，三个作用对象

§3 里写过一个判断名字的标准：

> **一个好的名字，应该能在三个尺度上都成立。**

深化 B 之后，这个标准被填满了，而且填得比原来更漂亮：

| 尺度 | impulse 作用在谁身上 | 具体表现 |
|---|---|---|
| **微观** | **自己** | 滑铲、墙跑、爬墙、翻越 |
| **中观** | **建筑** | C4、破门锤、霰弹破墙 |
| **宏观** | **对手** | 子弹的停止作用、击退、受伤减速 |

**三个对象，同一个物理量。**

这就是为什么说它从「移动的名字」升级成了「力的名字」。

---

## 附-5 意外收获：Project Breakpoint 反而更准了

`breakpoint` = 断点。这个双关之前有点虚（调试器的断点 + 抽象的「突破点」）。

深化 B 之后，它**变得非常字面**：

> **你就是在墙上打 breakpoint。**

一个 `breakpoint` 就是一个四档洞口。

内部代号从「凑合能用」变成了「**精准描述**」。

---

## 附-6 一个必须说的风险

深化 B 之后，**破坏系统的权重明显上升**：

- 占装备槽
- 有回合预算（每回合 2 次）
- 有加固博弈（防守方 1 处 / 回合）
- 有 8 条技术约束
- 有 6 条待验证假设

**注意力容易从「移动」偏到「拆墙」。**

不过有一个数据能让人放心：

| 系统 | 频率 | 单次影响 |
|---|---|---|
| **移动（parkour）** | **每秒都在发生** | 低 |
| **破坏** | 每回合 2 次 | 高（结构性） |

**名字应该指向高频动作**，因为玩家 95% 的时间在移动，只有 5% 在拆墙。

所以 IMPULSE 指向移动是对的。

### 真正的风险不是名字

如果做出来玩家觉得「这游戏主要好玩在拆墙」，那说明**移动系统没做够**，
而不是名字取错了。

这要靠 M2–M3 的手感验收来防，不能靠改名字解决。

---

## 附-7 术语分层：防止 impulse 被滥用

深化 B 之后，`impulse` 的覆盖面变大了，**必须防止一个词包打天下**：

| 概念 | 建议用词 | 理由 |
|---|---|---|
| **移动资源（0–6）** | **impulse** | 唯一正式用法，玩家要天天说 |
| 破坏动作 | **breach** | 和行业术语一致（breach / breaching） |
| 破坏的四档 | **breach level 1–4** | 不要叫 impulse level，会和资源混淆 |
| 命中反馈 | **IMPACT** | 保持 |
| C4 本体 | **impulse charge**（可选） | 既贴物理又与游戏名呼应，且不占用资源词的语义 |

**原则：只有一个东西叫 impulse。**

这样 HUD 上的 `IMP ● ● ● ● ○ ○` 永远没有歧义。

> 顺带一个想法：C4 叫 **impulse charge**（冲量装药）挺合适——
> 它既符合物理（装药 = 集中释放冲量），又和游戏名呼应，
> 而且不会和「移动资源 impulse」打架。
> 这类「呼应但不冲突」的命名，比全都叫 impulse 更好。

---

## 附-8 本节小结

| 问题 | 答案 |
|---|---|
| 深化 B 后名字还契合吗 | ✅ **更契合** |
| 需要改名吗 | ❌ 不需要 |
| 为什么 | 破坏 = 冲量；四档 = 冲量分级；三个对象都在同一个物理量上 |
| 内部代号要改吗 | ❌ 不用，Breakpoint 反而变准了 |
| 要注意什么 | 术语分层（impulse / breach / impact），别混用 |
| 真正的风险 | 移动系统被破坏系统抢戏——靠手感验收防，不靠改名 |
