## 2. 范围

### in（这一轮只做这些）

1. `sim/data/weapons.toml` + `WeaponDef` 加载（**不塞进 `movement.toml`**：它有自己的哈希，调枪不该让移动参数哈希变）。
   **加一把枪 = 加一段数据，不改代码**；字段按 D5 随任务分批长（仿 TacZ 只仿结构，见 ADR 0007）
2. 开火输入链路：`sim/input` → `MoveInput` → `session` → 快照（`firing/reloading/ads` 三个 flags，v6 已预留位）
3. hitscan + hitbox 历史回溯（历史缓冲已实现，补回溯窗口 6 tick）
4. 三段部位判定 + 伤害衰减 + 穿透（**先定模型**，见 §4 决策 1）
5. `hp` / `armor` / `weapon` 组进快照（v6 已能传 hp/armor，Weapon 组等 M6.7 填值）
6. 死亡 / 重生 / `alive` 位
7. 后坐力查表 + `punch` 增量校正（A4：**后坐力 index 不进快照**）
8. hitmarker / 伤害数字（表现层，最小实现）

### out（明确不做，做了就是范围蔓延）

- ❌ 第三人称动画、第一人称视角模型 → M7 / M8
- ❌ 音频、楼层低通 → M7
- ❌ 40×40 可玩图、爆破、C4、经济结算 → M8
- ❌ 5v5 选边、队伍色、记分板 → M8（`kFieldTeam` 只预留位）
- ❌ 武器美术资源（先用占位几何体）
- ❌ 改 tick 率；除协议版本号外的全局重命名
- ❌ 高速弹道（线段扫掠 vs 胶囊）→ 随 M8 狙击枪（`BACKLOG FEAT-12`，D4 已定）
- ❌ 性能优化（余量 1600×，现在做是负收益）

## 4. 开工前必须拍板的三个决策

| # | 问题 | 决定 | 状态 |
|---|---|---|---|
| D1 | 穿透两套模型谁优先 | **武器决定、地图能否决**：`_penetrable 0` 任何武器都打不穿；`1` 只有 `penetration_count>=1` 能穿，每层伤害 ×0.7 | **已定** |
| D2 | 护甲怎么结算 | **按部位**：爆头=真伤（不经护甲）；胸/腿先扣护甲池、扣完才扣血（`absorb_percent=100`）；25/25再生/50 与 5 s/10 s 保留 | **已定** |
| D3 | 热重载 | **暂不做**：删掉"可重载"的说法，记 `DEBT-22`（lead M7），等 weapons.toml 落地后一次做两个文件 | **已定** |

| D4 | 高速弹道（线段扫掠 vs 胶囊）要不要进 M6 | **不进 M6**：v0.1 全是 hitscan，它没有使用者；转 `BACKLOG FEAT-12`（随 M8 狙击枪做），M6 验收里删去这一项 | **已定**（按 §4 建议默认） |
| D5 | WeaponDef 的字段边界 | **按任务分批**：M6.1 只落 M6.1–M6.7 有使用者的字段（伤害/衰减/rpm/弹匣/换弹/射程/穿透）；后坐力随 M6.10，ADS/曳光随 M6.11；`draw_time/put_away_time/sprint_time/bolt_action_time/weight/knockback/bullet_amount` 没有任务，暂不落（`speed_coefficient` 另记 FEAT-13） | **已定**（按 §4 建议默认） |

> 三条（D1–D3）都落在 `docs/decisions/0006-penetration-armor-reload.md`，D2 的代码已按该文实现
> （`apply_damage(vitals, damage, zone, params)`，`--test-health` 覆盖爆头真伤与腿部走护甲）。
> **不许在代码里"先这么写"** —— 那是下一轮审计的 P1。
>
> **"仿 TacZ 手感"的边界**（ADR 0007）：仿的是结构（移动状态 × 距离的扩散矩阵、按状态配置的
> 后坐力、开火节奏时间），不是它的代码、表结构或数值。字段随 M6.10 / M6.11 分批进 `weapons.toml`，
> 每个字段进来时都必须有使用者。
