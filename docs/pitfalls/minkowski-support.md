# Minkowski 支撑方向：min 与 max 决定「相交」还是「包含」

- 日期：2026-10-18
- 现象：盒体扫掠对 0.1 m 墙 **100/100 次穿透**，玩家直接走过墙、落到 -894 m。
- 代价：碰撞层等于没有；而且第一个 tick 不崩，只表现为「掉出地图」。
- 根因：把盒体沿平面法线的支撑距离写成了 `max`。
  - 盒心 `c`、盒偏移集合 `K`、平面 `n.x <= d`；
  - 盒**与**凸体相交 ⟺ ∃k∈K: `n.(c+k) <= d` ⟺ `n.c <= d - min_k(n.k)`；
  - 用 `max` 得到的是「整个盒都在半空间内」，也就是盒**完全在凸体内**，
    于是贴着墙的盒全被判定为「不接触」而直接放行。
- 判据：`headless_sim --test-wall` 任一速度出现 penetrations>0 即失败；
  盒体在 0.1 m 墙前应停在 `x = -0.455`（墙面 -0.05 减玩家半径 0.405）。
- 附带教训：**先写会失败的测试，再修实现**。这个 bug 是靠「100 次里 100 次失败」
  一眼看出来的，如果只跑 1 次、又恰好停在墙前，就可能被误判为通过。
