# 接触 epsilon 把「已经贴上」判成「没碰到」

- 日期：2026-10-18
- 现象：修好扫掠方向后，玩家贴墙静止时每 tick 向前挤 **19 mm**；走到 20/35 cm 台阶前原地蹭，永远爬不上去。
- 代价：表面上是「台阶没做」，实际是碰撞层在漏；而漏的速度与帧率相关，换台机器表现还不一样。
- 根因：进入分数 `f = (d1 - kClipEpsilon) / (d1 - d2)`。
  玩家停下时正好距墙面一个 `kClipEpsilon`（1 mm），下一次 trace 的 `d1 == eps`，
  分子为 0 或 **-1e-9**；代码里 `if (enter < 0) continue;` 把这一小段负数当成
  「没碰到」丢弃 → 本 tick 不裁剪速度 → 前进一个步长，再被下一 tick 判到。
- 修复：进入分数**钳到 0**（已经发生的进入就是 fraction 0 的命中），不要丢弃。
- 反向风险：钳到 0 很容易把**沿墙滑动**也钳死（切向速度被误判成撞墙）。
  所以修复必须同时验证两条：
  - 贴墙静止 100 tick，位置变化 < 1 mm；
  - 以 45° 撞墙 20 tick，沿墙位移 > 0.5 m（实测 1.875 m）。
- 判据：`headless_sim --test-wall`（穿透 + 静止 + 滑墙）、`--test-step`（台阶/挡墙/蹲下空间）。
