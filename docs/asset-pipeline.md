# 资产管线（建模 / 动画 / 素材来源）

> 立的规矩在这里；**现状**是：地图由 brush 生成 mesh，玩家是胶囊，枪还没有模型。
> 这份文件的作用是：等真正开始建模那天，规则、预算、闸门、台账都已经就位。

## 0. 一条铁律：视觉不进判定

```
碰撞 + 判定   只认 .map brush 与 sim/data/*.toml 里的参数（进 geometry_hash / params_hash）
视觉          GLTF / 程序 mesh / 动画，随便换，不进任何哈希
```

理由不是洁癖：换一把枪的贴图如果改了 `geometry_hash`，房间两侧会互相拒局，旧 demo 全部回放失败。
所以模型只能挂在**表现层**，永远不回头影响 sim。

推论（都已在计划书 §2.2 定过）：

- **不做骨骼 hitbox**：动画变形 → “看着打中了却不判定”。判定是胶囊 + 三段高度。
- **不做模型驱动的碰撞**：凸体只在 `.map` 里，由 `tools/blender/bp_export_map.py` 导出。

## 1. 三类资产，三条路

### 1.1 地图（M7.4）

Blender 建一次，**导出两份**：

| 用途 | 格式 | 谁读 | 工具 |
|---|---|---|---|
| 碰撞 / 判定 | `.map`（凸体平面） | sim | `tools/blender/bp_export_map.py`（已有，自测过 40×40 房间） |
| 外观 | `.glb` | Godot 只负责画 | Blender 自带导出 |

约束：

- **凸体必须真凸**：L 形墙拆成两个 box。导出器会拒绝非凸面（宁可报错，也不生成能穿模的碰撞）。
- 视觉网格可以合并、加倒角、贴材质，**不要求和凸体一一对应**。
- 两侧的**包围盒必须一致**（±0.05 m）；不一致说明其中一份改过而另一份忘了导出。

### 1.2 角色（M7.5 远端姿态）

- 骨骼只驱动视觉；判定仍是胶囊（半径/高度/蹲下高度来自 `movement.toml`）。
- 蹲下：节点 `scale.y` 缩放，判定侧读 `crouch_height`，两边不共享数值。
- 动画来源可以是 Mixamo（免费，人形重定向）或自己 K 的关键帧。

### 1.3 视角模型（M7.6，FEAT-16）

- 独立场景，挂在相机下，**完全不碰 sim**。
- 后坐力偏移由 `get_recoil_offset()` 提供，视角模型照着摆，不自己算。
- 动画时长必须**服从数据**：`weapons.toml` 的 `reload_seconds`（步枪 2.3 s = 147 tick）是权威；
  买来的动画如果是 1.8 s，要**重定时间到 2.3 s**，而不是把 `reload_seconds` 改成 1.8。
  后者会改 TTK、改平衡、让所有 demo 失效 —— 这是最容易犯的错。

## 2. 预算（先定死，不然一定失控）

| 项 | 上限 | 依据 |
|---|---|---|
| 角色三角面 | 15k | 5v5，同屏最多 10 个 |
| 地图总三角面 | 150k | 40×40 图 + 2.5 层 |
| 单件静态物件 | 8k | 箱子 / 门 / 掩体 |
| 角色贴图 | 1024² | 只此一档 |
| 武器贴图 | 2048² | 视角模型要看细节 |
| 每个物件的材质数 | 3 | draw call |

### 2.1 单位与轴向（Blender → Godot）

| 项 | 规定 |
|---|---|
| 单位 | **米**（Blender 里先 apply scale） |
| 轴向 | +Y up、-Z forward（glTF 标准；Godot 直接吃） |
| pivot | **脚底 / 底面**，不是几何中心 |
| 节点缩放 | 导出时必须是 1.0（`Object > Apply > All Transforms`） |
| 命名 | `sm_<类别>_<名字>`（静态）、`sk_<类别>_<名字>`（骨骼）、`wp_<名字>`（武器） |

pivot 这条最容易忘：origin 在几何中心时，一摆 `origin` 模型就陷进地里，而判定盒在正确高度 ——
表现与判定分家，正是这一整份文件要防的事。

## 3. 素材从哪来（含许可陷阱）

| 来源 | 许可 | 能不能用 |
|---|---|---|
| [Kenney](https://kenney.nl)、[Quaternius](https://quaternius.com) | **CC0** | ✅ 直接用，不用署名 |
| [Sketchfab](https://help.sketchfab.com/en/articles/16152217-downloading-3d-models) 筛 CC0/CC-BY | CC0 / CC-BY | ✅ 但要逐个看，很多是 NC 或 “Editorial use” |
| [Mixamo](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)（动画） | Adobe 免费条款 | ⚠️ 可用在项目里，**不能当素材包再分发**；绑定 Mixamo 骨骼 |
| [Fab](https://www.fab.com/eula) / Unity Asset Store / TurboSquid | 商业许可 | ⚠️ **逐个看引擎限制**；Unity 专属资产不能用在 Godot |

### 3.1 三个坑

1. **引擎绑定许可**：Unity Asset Store 的资产基本只能用于 Unity；Epic 老市场是 Unreal 专用。
   Fab 改革后有的资产允许跨引擎，但**必须看 EULA 里有没有 any-engine 字样**。买错了是违约，不是“应该没事”。
2. **扒模**：Sketchfab 上大量 CS / 使命召唤的枪模标着 “free” 却没有许可 —— 那是侵权复制品，
   进仓库等于埋雷。判断：作者是否自己建模、有没有制作过程、许可是否明确。
3. **静态枪模 ≠ 视角模型**：下载到的通常只是一把枪。FPS 需要的是**第一人称手臂 + 枪 + 换弹/开镜/开火动画**，
   这些几乎不随模型附带；带完整 FP 手臂动画的包通常是付费的（几十美元级），且风格要统一。

### 3.2 本项目的取舍

- **M7.4 之前不买任何东西**：先用 CC0 低模占位（Kenney / Quaternius），人形动画用 Mixamo。
- **M7.6 视角模型**时再花钱买“带 FP 手臂 + 换弹动画”的包，而不是一把静态枪。
- **永远不**：CS/Valve 扒模、来源不明的“免费”枪模、CC BY-NC-ND（铁律 H）。

## 4. 台账（不登记就进不了构建产物）

每个资产进仓库前，在 `docs/assets-licenses.md` 加一行：

| 资产 | 来源 URL | 许可 | 作者 | 进构建产物 | 备注 |
|---|---|---|---|---|---|
| `sm_prop_crate.glb` | kenney.nl/... | CC0 | Kenney | ✅ | 占位 |

闸门 `tools/check_assets.py` 会扫 `assets/**/*.glb`，逐条比对：

| 检查 | 判据 |
|---|---|
| 台账 | 每个 `.glb` 必须在台账里有同名行 |
| 许可 | 那一行不得含 `NC` / `ND` / `NonCommercial` / `NoDerivatives` |
| 单位 | 包围盒最大值在 0.01–200 m 之间（防“按厘米导出”） |
| pivot | 包围盒最低点 |z| ≤ 0.02 m（脚底/底面） |
| 缩放 | 节点 scale 必须是 1.0 |
| 面数 | ≤ 200k（单文件粗上限；分类预算见 §2，靠 review） |

`python tools/check_assets.py --selftest` 用合成 GLB 证明每条规则**真的会红**（见 §6）。

## 5. 不能自动验的东西

- **好不好看**、风格统不统一、动画顺不顺 —— 只能看。
- 视角模型与准星的对齐（枪口和弹道是否一致）—— 只能看得出来，或靠 `godot_check` 的曳光起点比对。
- 付费资产的 EULA 是否允许本项目使用 —— 人工读，读不懂就问卖家。

别把“闸门绿了”当成“资产没问题”，闸门只挡结构性错误。
