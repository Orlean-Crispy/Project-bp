# ADR 0003 — HP 与护甲

- 日期：2026-10-19
- 状态：数值已定；**吸收比例与结算顺序已被 ADR 0006 取代**（2026-10-24：护甲按部位结算、爆头真伤）

## 决定

| 项 | 值 |
|---|---|
| HP | 100 |
| 小甲 | 25，不恢复 |
| 再生甲 | 25，受伤后随时间恢复 |
| 大甲 | 50，不恢复 |

## 提案（其中前两条已由 ADR 0006 取代）

- ~~护甲吸收 66%~~ → ADR 0006：胸/腿先扣护甲池（100%），爆头真伤、不经护甲。
- 再生甲：5 s 无伤害后开始恢复，10 s 从 0 回满（ADR 0006 确认保留）。
- 伤害全部整数运算（避免浮点影响确定性与回放）。

## 影响

- TTK 复算：重甲 + 25 伤害/发 @600 RPM → 躯干 6 发 = 0.60 s（计划书区间 0.6–1.2 s 的下沿）。
- 爆头按 §6.10 取 ×5（计划书已定）；与护甲的结算顺序在 M6 实现时确认。
- 数据：sim/data/combat.toml；测试：headless_sim --test-health。

## 未决

- 吸收比例、再生节奏需要试玩确认；若改，只改 combat.toml，不动代码。
